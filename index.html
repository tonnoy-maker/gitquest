Quick field guide

⌁
Git is version control

It tracks snapshots of your project so you can inspect or restore changes.

●
Commit = local save point

A commit records staged changes in your local repository.

⇧
Push = send commits

Push uploads local commits to a remote repository such as GitHub.

⑂
Branch = separate line of work

Build a feature without changing the main branch until you're ready.

GitQuest is an educational simulation. It never connects to your GitHub account or runs real Git commands.
