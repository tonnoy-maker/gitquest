# GitQuest — Git & GitHub Adventure

GitQuest is a small, responsive browser game that teaches Git and GitHub through six missions and a visual command simulator.

## Play it now

**No install, API key, terminal, or backend is required.** Open `index.html` in any recent desktop or mobile browser. The quiz and repository playground run locally in the page.

## Share it with anyone using GitHub Pages

1. Sign in to GitHub and create a **public** repository named `gitquest`.
2. On the repository page, choose **Add file → Upload files**.
3. Upload `index.html` and `README.md` into the repository root. (`.nojekyll` and `.gitignore` are optional.) Make sure `index.html` is at the top level, not inside another `gitquest` folder.
4. Commit the uploaded files to the `main` branch.
5. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. After GitHub Pages finishes publishing, share this URL (replace the username): `https://YOUR-USERNAME.github.io/gitquest/`.

Future updates to the files on `main` publish to the same URL automatically. GitHub may take a minute or two to publish the first version.

## What you can learn

- Stage and commit changes
- Create and switch branches
- Merge a feature branch into `main`
- Push commits to a remote such as GitHub
- Read commit history
- Understand the purpose of a pull request

## Scope and safety

The repository playground is intentionally simulated. It does not execute real shell commands, read local files, or connect to a GitHub account. The game is a single static HTML page with inline CSS and JavaScript; it can be hosted on any static web host.
